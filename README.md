# 📂 Post Storage — система хранения постов

Автономная система для ведения базы постов каналов и сообществ. Браузерный интерфейс для работы с таблицей постов (открытие, редактирование, фильтрация, сохранение) + структура папок для медиа-материалов. **Работает полностью офлайн** — без сервера и интернета.

## ✨ Возможности

- 📋 **Таблица постов** — открытие, добавление, редактирование, удаление записей
- 🔎 **Фильтры и поиск** — по каналу, статусу, площадке, дате
- 📊 **KPI-панель** — сводка по статусам и количеству постов
- 💾 **Сохранение в Excel** — скачивание обновлённого `xlsx`-файла
- 🗂 **Структура медиа** — папки `00_Новые / 01_Опубликованные / 02_Архив` на каждый канал
- 🚫 **Без зависимостей** — только HTML + одна JS-библиотека чтения Excel (в `vendor/`)

## 📁 Структура

```
post-storage/
├── база_постов_интерфейс.html   # Браузерный интерфейс (открывается двойным кликом)
├── база_постов.xlsx             # Исходная таблица постов (единый источник данных)
├── vendor/
│   └── xlsx.full.min.js         # Библиотека чтения/записи Excel (не удалять!)
├── Медиа/
│   ├── Канал-Пример 1/
│   │   ├── 00_Новые/
│   │   ├── 01_Опубликованные/
│   │   └── 02_Архив/
│   └── Канал-Пример 2/
│       ├── 00_Новые/
│       ├── 01_Опубликованные/
│       └── 02_Архив/
└── ПРОЧТИ МЕНЯ.txt              # Инструкция
```

## 🚀 Как пользоваться

1. Откройте `база_постов_интерфейс.html` в браузере (Chrome/Edge/Yandex).
2. Нажмите **«Открыть база_постов.xlsx»** — в таблице появятся посты.
3. Добавляйте, редактируйте, удаляйте, фильтруйте и ищите посты.
4. В конце нажмите **«Скачать обновлённый файл»** и замените им `база_постов.xlsx` в папке.
5. Медиа-материалы раскладывайте в `Медиа/<Канал>/00_Новые` (или Опубликованные/Архив) и указывайте путь в столбце «Медиафайлы» поста.

## ⚠️ Важно

- Держите HTML, папку `vendor` и xlsx **в одной папке** — не разносите.
- Меняйте посты либо в таблице, либо в интерфейсе, но не в обоих одновременно — иначе одно перезапишет другое.
- При сохранении из интерфейса оформление Excel упрощается, данные не теряются.
- Чтобы перенести на другой компьютер — скопируйте всю папку целиком.
